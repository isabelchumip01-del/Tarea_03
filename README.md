# Factores que inciden en la representatividad de las mujeres para la toma de decisiones en la gestión del recurso hídrico

**Autora:** Isabel Chumi

## Descripción

Este repositorio contiene el análisis de datos sobre la participación y representatividad de las mujeres en la gestión del recurso hídrico, desarrollado mediante R y Quarto. Incluye el análisis estadístico y la representación geoespacial de las tomas de agua de la Junta de Riego y Drenaje Machángara.
